When the internet disappears,
knowledge stays.

Kioo is an AI assistant that answers from the documents on your own computer, shows exactly which passage each answer came from, and keeps working with the internet turned off.

Install KiooSee the demo

Important: this website only describes Kioo. The AI does not run here. Kioo runs on your own computer, so your documents never come to this site.

Features

Local open-weight AI

Runs a model such as Qwen2.5 1.5B through Ollama on your computer. No remote AI service in the core workflow.

Your documents

Import text, Markdown or PDF files into a local library. Remove them any time.

Answers with sources

Every answer lists the passages it used, with the document and page. Sources come from the index, not from the model.

Honest when it does not know

If your documents do not contain the answer, Kioo says so instead of guessing.

English and French

Ask in English or French. The interface is available in both.

Open source

MIT licensed. Change the model, the prompt or the code.

How it works

  1. Import. Kioo reads your file, cuts it into short passages and saves them on your computer.
  2. Search. Your question is matched to the most relevant passages with a local keyword search (BM25). If nothing is relevant, Kioo stops and tells you.
  3. Answer. The local model is asked to answer using only those passages, and to say "not found" otherwise.
  4. Check. The answer is shown next to the real passages, so you can verify it.

A small model can still make mistakes. That is why Kioo always shows its sources and never presents an answer as verified fact.

Privacy

Kioo's local mode processes imported documents and questions on your device. The core question-answering workflow does not require uploading your documents to a remote AI provider. Internet access is required initially to obtain the application dependencies and model unless these have already been installed.

There are no accounts, no analytics and no API keys. The server listens only on your own computer by default.

Installation (Windows, PowerShell)

You need Node.js (LTS), Git and Ollama.

git clone https://github.com/Bientechsavvy/kioo.git
cd kioo
ollama pull qwen2.5:1.5b
npm run install:all
npm run build
npm start

Then open http://127.0.0.1:8787. The status line shows whether the server and the model are really ready.
